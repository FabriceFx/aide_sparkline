## 🇫🇷 Version Française

> Aide Sparkline est un script (Add-on) pour Google Sheets qui fournit une interface graphique intégrée (barre latérale) permettant de générer facilement et visuellement des formules `SPARKLINE`.

<a href="README.md"><img src="https://img.shields.io/badge/Status-Production-brightgreen?style=for-the-badge" alt="Status: Production"></a>

### ✨ Fonctionnalités clés

- 📊 **Interface visuelle intuitive** : Barre latérale intégrée directement dans Google Sheets.
- ⚡ **Sélection facile des plages** : Boutons pour récupérer automatiquement la plage de données sélectionnée et la cellule cible.
- 🛠️ **Types de graphiques multiples** : Ligne (Tendance), Barre (Progression), Colonne (Comparaison), Gagné/Perdu (Booléen).
- 🎨 **Personnalisation avancée** : Couleurs, épaisseur des traits, gestion des cellules vides, définition des axes, etc.
- 🤖 **Aperçu en temps réel** : Visualisez le rendu du graphique et la formule générée avant de l'insérer.
- 🚀 **Insertion en un clic** : Insère la formule prête à l'emploi directement dans la cellule cible choisie.

---

### 🚀 Installation & configuration

1. Ouvrez votre document Google Sheets.
2. Allez dans **Extensions > Apps Script**.
3. Supprimez le code par défaut et remplacez-le par le contenu du fichier `Code.gs`.
4. Ajoutez un nouveau fichier HTML (`Fichier > Nouveau > HTML`), nommez-le `sidebar.html` (très important de respecter ce nom) et collez-y le contenu du fichier `sidebar.html`.
5. Enregistrez le projet (Ctrl+S / Cmd+S).
6. Retournez sur votre Google Sheets et actualisez la page.
7. Un nouveau menu **"📊 Aide Sparkline"** apparaîtra dans la barre de menu de Google Sheets.

---

### 📖 Exemples d'utilisation

1. Cliquez sur le menu **📊 Aide Sparkline > Ouvrir l'assistant** pour afficher la barre latérale.
2. Sélectionnez les données, puis cliquez sur **Obtenir** à côté de "Plage de données".
3. Sélectionnez la cellule cible et cliquez sur **Obtenir** à côté de "Cellule cible".
4. Choisissez le type de graphique et personnalisez les options.
5. Vérifiez l'aperçu visuel et la formule générée.
6. Cliquez sur **Insérer** pour appliquer la formule.

## 🇬🇧 English Version

> Aide Sparkline is a Google Sheets Add-on script providing an integrated graphical interface (sidebar) to easily and visually generate `SPARKLINE` formulas.

### ✨ Key Features

- 📊 **Intuitive visual interface**: Sidebar integrated directly into Google Sheets.
- ⚡ **Easy range selection**: Buttons to automatically get the selected data range and target cell.
- 🛠️ **Multiple chart types**: Line (Trend), Bar (Progress), Column (Comparison), Win/Loss (Boolean).
- 🎨 **Advanced customization**: Colors, line thickness, empty cell management, axes definition, etc.
- 🤖 **Real-time preview**: See the chart rendering and generated formula before inserting it.
- 🚀 **One-click insertion**: Inserts the ready-to-use formula directly into the chosen target cell.

---

### 🚀 Installation & Setup

1. Open your Google Sheets document.
2. Go to **Extensions > Apps Script**.
3. Delete the default code and replace it with the contents of the `Code.gs` file.
4. Add a new HTML file (`File > New > HTML`), name it `sidebar.html` (very important), and paste the contents of the `sidebar.html` file into it.
5. Save the project (Ctrl+S / Cmd+S).
6. Return to your Google Sheets and refresh the page.
7. A new **"📊 Aide Sparkline"** menu will appear in the Google Sheets menu bar.

---

### 📖 Usage Examples

1. Click on the **📊 Aide Sparkline > Open assistant** menu to display the sidebar.
2. Select the data, then click **Get** next to "Data range".
3. Select the target cell and click **Get** next to "Target cell".
4. Choose the chart type and customize the options.
5. Check the visual preview and generated formula.
6. Click **Insert** to apply the formula.
